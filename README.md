# MY LITTLE PONY: THE LAST SAVE

### `Friendship was never deleted.`

Локальная браузерная хоррор-игра. Проект запускается на компьютере как обычный сайт: небольшой Node.js-сервер отдаёт HTML/CSS/JS, а сама игра работает в Chrome, Edge или другом браузере.

## Запуск

### Windows — одним кликом

Запусти:

```text
START_GAME.bat
```

Он проверит Node.js, запустит локальный сервер и автоматически откроет игру:

```text
http://127.0.0.1:4173/
```

Пока игра запущена, окно `START_GAME.bat` нужно оставить открытым. Закрытие этого окна остановит локальный сервер.

### Вручную

```bash
npm start
```

или:

```bash
node server.js
```

После этого открой `http://127.0.0.1:4173/`.

## Обновления

Игра больше не зависит от Electron и не требует установки тяжёлых пакетов. После обновления исходников достаточно заменить папку проекта и снова запустить `START_GAME.bat`.

## Системы игры

- Шесть стартовых персонажей.
- Семь актов сюжета с ветвлениями.
- Friendship, Courage, Attention, Trust и скрытая Memory.
- Отношения с главными персонажами.
- Инвентарь и сюжетные предметы.
- Сохранения и загрузки как часть сюжета.
- Меняющийся мир, ложные ошибки и разрыв четвёртой стены.
- 18 мини-игр.
- Пять режимов сложности и скрытый `???`.
- Шесть концовок и New Game+.

## Файлы

`index.html` — оболочка игры.

`styles.css` — интерфейс и визуальные эффекты.

`game.js` — игровой runtime, сюжет и мини-игры.

`server.js` — локальный HTTP-сервер без сторонних зависимостей.

`START_GAME.bat` — запуск игры в браузере одним кликом на Windows.
